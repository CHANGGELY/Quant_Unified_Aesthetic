# 十号隐马尔可夫策略（HMM）— 中性选币（多空对冲）

这个策略想解决什么问题？
- 我们希望对每个币，输出「未来 8 小时」更像哪种市场状态：`上涨 / 下跌 / 震荡`，以及对应概率。
- 然后做一个**中性选币**（也叫“多空对冲”）：  
  - 做多：上涨概率 Top 10% 的币  
  - 做空：下跌概率 Top 10% 的币  
  - 目标是让组合更“稳”：不赌大盘方向，赚“选币差异”。

为什么用 HMM（Hidden Markov Model，隐马尔可夫模型）？
- 你可以把它理解成：市场真实处在一个“看不见的状态机”里（隐状态），比如上涨/下跌/震荡；
- 我们能看到的是 K 线、成交量这些“外显数据”（观测）；
- HMM 会用 **鲍姆-威尔奇算法（Baum–Welch）** 去把：
  - 每个状态下“观测数据长什么样”（发射分布）
  - 状态之间“怎么切换”（转移矩阵）
 这些参数从历史数据里自动学出来。

数据来源（真实数据，不用模拟数据）
- 本策略默认读取你给的压缩包（zip）：
  - `数据/历史行情中心/币对分类全量小时 K 数据/coin-binance-swap-candle-csv-1h-2025-12-19.zip`
- 里面是币安合约的 1h K 线（csv），每个币一份文件。

特征（输入）是不是把“所有数据都用上了”？
- 你提出的三类：**开高收低（OHLC）/ 成交量 / 成交额**，已经覆盖了 K 线里最核心的“价格 + 量”信息。
- 但要注意：**不能直接把“价格的绝对值”喂给模型**，因为不同币价格差太大（比如 BTC 10 万、DOGE 0.1），模型会被尺度带偏。
- 所以我们会把它们变成“对比更公平”的特征，例如：
  - `1小时对数收益`（log return）：用收盘价变化表示方向
  - `振幅`（high-low 的比例）：用来刻画“震荡强不强”
  - `K线实体`（close-open 的比例）：用来刻画“这根 K 是涨还是跌”
  - `成交量/成交额的对数变化`：用来刻画资金活跃度变化

实现细节（你关心的点）
- **使用第三方库**：HMM 用的是 `hmmlearn.GaussianHMM`
- **全协方差（full covariance）**：每个状态都有一个完整协方差矩阵，能学习特征之间的联动关系

如何运行（推荐 Python 3.13 + UTF-8）
0) 激活项目虚拟环境（本仓库已把 `.venv` 切到 Python 3.13）：
   - `source .venv/bin/activate`
1) 训练模型（会保存到 `models/`）：
   - `python -X utf8 Quant_Unified/策略仓库/十号隐马尔可夫策略/train.py`
2) 输出最新一轮选币结果（Top10% 多/空）：
   - `python -X utf8 Quant_Unified/策略仓库/十号隐马尔可夫策略/select_coins.py`
3) 回测 + 资金曲线 + 报告（会输出 HTML 报告文件）：
   - `python -X utf8 Quant_Unified/策略仓库/十号隐马尔可夫策略/backtest.py --no-chart`

常用可调参数（环境变量）
- `HMM10_MAX_TRAIN_SYMBOLS`：训练用多少个币（默认 200）
- `HMM10_MAX_BARS_PER_SYMBOL`：每币最多用多少根 1h K（默认 6000）
- `HMM10_MAX_ITER`：EM 最大迭代次数（默认 30）
- `HMM10_RANGE_TH`：把“震荡”定义成 `|8小时累计对数收益| <= theta`（默认 0.005）
- `HMM10_BT_START`：回测开始时间（默认 2021-01-01）
- `HMM10_BT_MAX_SYMBOLS`：回测最多跑多少币（默认 300）
