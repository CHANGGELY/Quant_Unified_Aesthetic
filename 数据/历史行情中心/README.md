# 历史行情中心

这个目录是全仓库唯一的历史行情数据存放处。
所有策略/服务的历史行情读写都应通过 `common_core.data_center` 来定位，避免把路径写死在代码里。

## 目录约定
- `分钟K线/`: 分钟级 K 线（H5 或 CSV 等）
- `行情数据/`: 实时采集的分片数据（常见为 Parquet）
- `行情数据_整理/`: 合并后的日级文件
- `行情数据_备份/`: 整理前备份
- `币安官方历史数据_raw/`: 官方原始下载文件
- `分钟级盘口/`: 盘口历史
- `外部数据/`: 第三方数据或外部来源

## 环境变量
- `QUANT_HIST_DATA_DIR`: 历史行情中心根目录（默认是仓库根目录下的 `数据/历史行情中心`）

## Git 说明
本目录默认不入库，仅保留本说明文件。
